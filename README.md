One kind, funny fortune for the houseplant on the windowsill, written to `/output/entry.txt` (92 characters, one line).

> The sun will find your window every morning this week, and you will drink it in like gossip.

## How it works

`main.ts` (Node 22) writes the fortune to `/output/entry.txt`, guarded to 1–120 characters, and reads it back to prove the write landed.

## Run

```sh
node main.ts
cat /output/entry.txt
```
